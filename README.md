# Таро для рынков — автопостинг в Telegram

Каждое утро с понедельника по субботу в 08:41 МСК бот:
1. берёт свежие данные: **IMOEX** и **RGBI** с MOEX ISS, **USD/RUB** — официальный курс ЦБ;
2. честно тянет 3 карты из 78 (криптостойкий ГСЧ, 30% шанс перевёрнутой);
3. сверяет вчерашний расклад с фактом и ведёт счёт точности оракула («карты угадали 2 из 3, точность 58%»);
4. пишет пост через Claude в стиле «циничный рыночный мистик»;
5. рисует картинку расклада и публикует в канал.

По воскресеньям вместо расклада выходят **итоги недели**: точность оракула, таблица попаданий по дням и активам, лучший прогноз и худший промах, движение рынка за неделю и «карта следующей недели». Выпустить итоги вручную: `python main.py --weekly`.

Если API Claude недоступен — уходит шаблонный пост, канал не пропускает день.

## Ключ Claude API

Подписка claude.ai (Pro/Max) не даёт доступа к API — это отдельный продукт с оплатой по факту.
1. platform.claude.com → войти → Billing → пополнить баланс (минимального платежа хватит на месяцы).
2. API Keys → Create Key → скопировать в секрет `ANTHROPIC_API_KEY`.
3. Там же можно задать месячный лимит расходов.

Расход: ~1,5 тыс. входных и ~0,6 тыс. выходных токенов на пост. На Sonnet 5.5 это около $0,01 за пост, ~$0,30 в месяц. На Haiku 4.5 (`ANTHROPIC_MODEL=claude-haiku-4-5-20251001`) — вдвое дешевле, но текст проще.

## Запуск за 15 минут

1. **Бот**: @BotFather → `/newbot` → токен. Добавьте бота в канал администратором с правом публикации.
2. **Ключ Claude**: console.anthropic.com → API Keys.
3. **Репозиторий**: залейте папку в приватный репозиторий GitHub.
4. **Settings → Secrets and variables → Actions**:
   - Secrets: `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` (`@имя_канала`), `ANTHROPIC_API_KEY`
   - Variables: `CHANNEL_HANDLE` (например `@tarot_market` — подпись на картинке)
5. **Actions → daily-tarot → Run workflow** — первый пост вручную. Дальше по расписанию.

Локально: `pip install -r requirements.txt && python main.py --dry-run` — сгенерирует текст и картинку без публикации.

## Настройки

| Что | Где |
|---|---|
| Время публикации | `cron` в `.github/workflows/daily.yml` (время в UTC) |
| Стиль, тон, длина текста | `STYLE` в `writer.py` |
| Модель | переменная `ANTHROPIC_MODEL` (по умолчанию `claude-sonnet-5-5`) |
| Новые активы | словарь `ASSETS` в `market.py` — картинка и текст подхватят автоматически (до 3–4 карт на картинке) |
| Рыночные значения карт | `deck.py` |
| Порог «боковика» для оценки | `FLAT` в `main.py` |

## Если GitHub-раннеры заблокируют MOEX/ЦБ

Запустите на любом VPS: `crontab -e` → `41 8 * * * cd /path/tarot_bot && python3 main.py` с переменными окружения из шага 4.

## Колода

Карты — сканы первого издания колоды Райдера–Уэйта–Смит 1909 г. (художница Памела Колман Смит, ум. 1951) из Wikimedia Commons. Это общественное достояние и в РФ, и в США: использовать можно, в том числе в коммерческом канале. Не берите поздние перекрашенные переиздания (US Games, с 1971 г.) — на них права есть. Название «Rider-Waite» — товарный знак US Games, в брендинге канала его лучше не использовать.
Если файла карты нет, рисуется запасной геометрический дизайн.
